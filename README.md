# 한 장 신문

신문 기사와 사진을 편집해 **A4 세로 한 장 PDF**로 저장하는 아침활동 편집실입니다.

- 공개 기사 URL에서 제목·본문·사진·출처 가져오기. 어린이조선일보의 Arc/Fusion 기사 구조를 지원합니다.
- 제목·본문·부제·사진 설명을 지면에서 직접 수정하고 입력창과 동기화합니다.
- 사진 업로드, 1단/2단 구성, 글꼴·크기·사진 높이·흑백 설정.
- 학년·반 각 10mm, 이름 32mm의 학생 기입 빈칸.
- 최소 10pt까지 한 장에 맞추며, 넘치면 PDF 저장을 중단합니다. 문장을 자동으로 생략하지 않습니다.
- 편집 파일(JSON) 저장·복원과 브라우저 임시 저장.
- 브라우저에서 A4 PDF 다운로드. 웹 PDF는 고해상도 이미지 방식이며, 글자 선택이 필요한 경우 **인쇄 → PDF로 저장**을 사용합니다.

## 데이터

기사 가져오기를 누르면 서버가 입력한 공개 기사 사이트와 사진 주소를 읽습니다. 편집한 본문·직접 올린 사진·완성 PDF는 브라우저에서 처리하며 별도 서버 데이터베이스에 저장하지 않습니다. 임시 저장은 같은 브라우저에만 남습니다. 중요한 작업은 편집 파일로 보관하세요.

로그인·구독·접근 제한은 우회하지 않습니다. 사이트 구조나 차단 정책에 따라 자동 가져오기가 안 될 수 있으며, 이때는 본문 붙여넣기와 사진 업로드를 사용할 수 있습니다. 기사와 사진의 이용 권한을 확인해 주세요. 저장소의 기본 예제는 직접 작성한 글입니다. 실제 신문 기사·사진과 사용자의 편집 파일은 저장소에 포함하지 않습니다.

## 개발

Node.js 22.13 이상을 사용합니다.

```sh
npm ci
npm run dev
node --test tests/article.test.mjs
npm run build
```

Vinext와 Cloudflare Workers용 서버리스 앱입니다. Sites의 Vite 빌드·배포 통합을 유지합니다.

- `app/route.ts`, `app/editor.html`: 편집실 화면
- `app/api/import/route.ts`, `app/lib/article.mjs`: 기사 추출 API
- `public/app.js`, `public/paper.css`: 편집과 A4 지면
- `public/web-pdf.js`: 브라우저 PDF 생성
- `public/vendor`: html2canvas 1.4.1, jsPDF 4.2.1 및 라이선스

API 키는 필요 없습니다. 인증 정보, `.env`, 로컬 실행 기록과 생성 PDF는 Git에 올리지 않습니다.
